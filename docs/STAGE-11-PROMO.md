# Stage 11 — Coders Arena Promo Website

The public home page now acts as the product/promo landing page while preserving the authenticated contest application routes.

## Sections

- Sticky navigation
- Hero / product positioning
- Arena UI preview
- Platform stats
- Feature grid
- How it works
- Contest CTA
- Footer

## Design direction

Minimal, high-contrast editorial style with compact typography, responsive layout, and no external image dependency. This keeps the landing page fast and deployable without additional assets.

## Routes

- `/` — public promo landing page
- `/contests` — contest discovery
- `/login` — authentication
- `/dashboard` — authenticated dashboard
